# XPrompt

Менеджер промптов для Windows: ловит промпты из браузера в один клик, хранит с превью, отдаёт по горячей клавише в любое окно.

## Структура

| Путь | Что это |
|---|---|
| `XPrompt.bat` | Единственное, по чему кликает пользователь |
| `updater.ps1` | Проверяет репозиторий, качает обновления, держит сервер запущенным |
| `app/` | Сама программа. Полностью заменяется при каждом обновлении |
| `app/extension/` | Расширение для Chrome / Edge |
| `CONTEXT.md` | Выжимка контекста проекта |

## Важно

Папка `data/` на компьютере пользователя (промпты, настройки, токен) в репозиторий не попадает и обновлением никогда не трогается.
