# XPrompt — контекст проекта

Зеркало страницы контекста в Notion. Подробности и журнал решений — там.

**Что делаем.** Десктопная программа для Windows: ловит промпты из браузера в один клик, хранит с превью картинок и видео, отдаёт по горячей клавише в любое окно, всё под мастер-паролем.

**Принципы.** Быстро важнее богато · всё локально, без облака и аккаунтов · ничего не теряется · без перегруза интерфейса.

**Пять сценариев.** Поймать промпт из интернета · достать и вставить куда угодно · привязать результат к промпту · разобрать входящие · собрать вариант из шаблона.

**Категории.** TTI, TTV, ITI, ITV, JB (jailbreak), CHAT, SYS плюс свои.

**Журнал проб.** По каждому промпту фиксируется: модель, дата, результат (прошло / частично / заблокировано), заметка.

**Чего не делаем.** Аккаунтов, облака, своего сервера · командной работы · генерации картинок · мобильной версии · Mac и Linux · весов, seed-ов и параметров под конкретные генераторы.

**Где живёт на компьютере.** `d:\Temp\0_dev\XPrompt`
